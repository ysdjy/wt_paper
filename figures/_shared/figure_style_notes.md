# Chapter 4 figure style notes

- Backend: Python (`matplotlib`, `pandas`, `numpy`, `scipy`) only.
- Final width: 7.2 in (about 183 mm), intended for a full-width two-column figure.
- Background: white; no shadows, gradients, 3D effects, or decorative framing.
- Typography: Arial-compatible sans serif, approximately 7–9 pt at final size.
- Vector text: SVG keeps text as editable `<text>` nodes; PDF uses Type-42 fonts.
- Raster preview: PNG at 600 dpi.
- Proposed method: deep blue-teal; shared backbone: grey-blue.
- Stage semantics: Early = cool blue, Middle = gold, Late = vermillion.
- All subplot captions use the exact pattern `(a) description`, centered below the panel.
- Heatmap colors support printed numbers and never replace the raw values.

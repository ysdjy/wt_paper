# Fig4-2 主比较 — Refinement Round 2 (版式简化与统一)

用户反馈：第一轮加的两个重边框block让图面更乱。本轮按用户明确的优先级重做：
**1. 内容清晰平衡 > 2. 边界感 > 3. 宁可只留一个浅色外框**。

## 改了哪些布局项

1. **边框系统简化**：删除了上一轮的两个内部深色block边框+左上角标签（"Overall D1
   comparison"/"Representative-method diagnostics"）。现在**只保留一个浅灰蓝色
   （`#B9C2CC`）、细线（`lw=0.9`）、圆角的整图外框**，内部不再画任何框线；上下两块的分组感改由
   充足的行间距和比例本身传达，不再依赖视觉边框。
2. **上下高度比例重分配**：GridSpec `height_ratios` 调整为
   `[1.30(row1), 0.11(spacer), 0.80(row2/d), 0.13(spacer), 1.00(row3/e)]`，row1（a,b,c）≈
   图高度的 39%，row2+row3（d + e1-e3）≈ 61%，落在要求的 38-40% / 60-62% 区间内。整图高度从
   160mm 降到 168mm（略增，用于容纳更充分的留白与对齐，而不是让内容更挤）。
3. **(a)(b)(c) 一行重排**：
   - 宽度比例改为 `[1.15, 1.0, 1.0]`（a 稍宽，b/c 相等中等宽度，而非此前 a 最宽、c 最窄）。
   - **三个子图的 caption 基线现在严格对齐**：此前 a/b/c 分别用 `y=-0.42/-0.24/-0.30`（不同的
     axes-fraction 偏移量），在同一行等高的三个 axes 下会导致视觉上不对齐；现在统一为
     `ROW1_CAPTION_Y = -0.40` 一个共享常量，三个 caption 都从这个常量取值，保证基线完全对齐。
   - (a) 的 x-tick 旋转角从 32°降到 30°，字号从 7.2 降到 7.0，caption 改为两行，与 e1/e2/e3
     的两行 caption 风格统一。
4. **(c) 视觉权重增强**（不改数据）：`elinewidth` 1.3→1.8，`capsize` 2.2→3.0，`capthick`
   新增 1.6，`markersize` 4.2→5.4；y 轴范围从 `±0.55` 压缩空行；x 轴范围进一步收紧
   （margin 2.0/1.5 → 1.6/1.2）。(c) 不再显得空，errorbar 本身更醒目。
5. **(d) confusion matrix 模块**：colorbar 宽度比例从 `0.10` 降到 `0.055`（更细，不再挤压矩阵
   主体）；四个矩阵本身保持等宽等高（GridSpec 等列宽，未改动）；方法名 caption
   风格本就统一（居中，`fontweight="normal"`），本轮未改。
6. **e1/e2/e3 统一**：
   - 三个 legend 从"悬浮在 axes 上方"（`bbox_to_anchor` y=1.16，占用额外垂直空间）改为
     **收进 axes 内部上方**（`loc="upper center"`, anchor y=1.0, 半透明白底），三图统一处理，
     不再挤压绘图区，也不再各自需要不同的顶部留白。
   - y 轴范围各自留出更多顶部余量（e1: 1.08→1.18；e2: 新增 ×1.35 headroom；e3 右轴新增
     ×1.42 headroom），确保图例、数据点、误差范围互不重叠。
   - **e3 双 y 轴弱化**：右轴（Smooth）颜色从纯黑 `#222222` 改为柔和灰蓝 `#5B6670`，线宽
     1.3→1.1，marker 1.3×3.6→3.0，右侧脊线更细（0.6pt）、同色调，刻度也同色调更浅——
     右轴现在读起来像"次要参考线"而不是与左轴竞争的主轴。

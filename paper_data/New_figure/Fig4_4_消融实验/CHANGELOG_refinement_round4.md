# Fig4-4 消融实验 — Refinement Round 4（数据核查 + 图例移入图内 + 多项版式微调）

## 0. 数据核查（用户要求）

**panel (a) 中 A3 / A4 的 Smooth 数值标注都显示 "0.021"，是否正确？**

核实结果：**正确，不是错误。** 真实冻结数值为 A3 = 0.020855、A4 = 0.020533——两者本就非常接近
但并不相同；四舍五入到小数点后三位时都落在 0.021。这是真实数据本身的巧合，不是标注 bug，
本轮未做任何改动。

## 改了哪些布局项

1. **panel (a) / (b) 图例移入图内**：原来悬浮在 axes 上方（`bbox_to_anchor` y=1.0，
   `loc="lower left"`），现在改为 `loc="upper left"`、锚点在 axes 内部顶部
   （`bbox_to_anchor=(0.01, 0.995)`），半透明白底，图例完全落在绘图区内部的空白处。
2. **panel (c) 改为整体共享图例**：删除了原来只出现在第一个子图（A1）内部的
   p_E/p_M/p_L 图例，改为在整个 (c) 四联图**上方正中间**放一个共享图例，横排三项，
   `handlelength` 从默认拉长到 `2.6`（线段更长更醒目）。
3. **panel (c) 子标题拉近**：A1/A4/A5/A6 四个子标题的偏移量从 `y=-0.30` 收紧到 `y=-0.18`，
   离各自图更近。
4. **panel (d) 改为整体共享图例**：删除了原来只挂在 (d1) 内部的 A1-A6 图例，改为在
   (d1)+(d2) 整体**上方正中间**放一个共享图例（横排 6 项）。
5. **panel (d) 线条变细**：A1-A6 六条曲线的线宽统一压缩到原来的 3/4
   （普通线 1.0→0.75，A5/A6 强调线 1.5→1.125）。
6. **panel (d1)/(d2) 子标题拉远**：原来 `y=-0.26` 太贴近图（和 x 轴标题 "Relative tool life"
   重叠），现在拉到 `y=-0.40`。
7. **panel (e) 顶部文字放大**：六个模块上方的角色标签（input / structure / core fusion /
   strongest ordering / final output）字号从 `5.6` 提高到 `7.0`。
8. **panel (e) 形状压扁**：六个模块（chevron + 最终圆角矩形）的高度统一压缩到原来的
   3/4，围绕同一垂直中心线（`y=0.64`）缩放，位置不变、只是变得更扁平。

## 修复过程中发现并解决的碰撞（打开 PNG 逐次核实）

- 第一次尝试把 (d) 的共享图例锚定在 `min(d_top+0.012, c_caption_top-0.024)`——这个
  安全下限选错了分支，导致图例被强行拉到 (c) 组标题的位置，两者完全重叠（"...representative
  configurationsA1 A2...A6" 糊在一起）。改为直接锚定在 `d_top+0.012`（axes_d 自身顶部）后，
  又发现两者之间的间隙（spacer2）不够容纳图例自身的高度，仍然贴得很紧；最终把 spacer2 从
  `0.34` 增加到 `0.50` 才彻底解决。
